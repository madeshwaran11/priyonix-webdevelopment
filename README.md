# PriyoniX Web Development Landing Page

Professional 3D animated landing page for the PriyoniX Web Development service.

## GitHub Pages structure

Keep all files in the repository root:

```text
priyonix-web-development/
├── index.html
├── styles.css
├── script.js
├── README.md
└── priyonix-logo.jpg
```

No `assets` folder is required.

## GitHub Pages deployment

1. Create a public GitHub repository named `priyonix-web-development`.
2. Upload all five files directly into the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`.
6. Click **Save**.
7. Wait for GitHub Pages to publish the site.

The live URL will normally be:

```text
https://YOUR-USERNAME.github.io/priyonix-web-development/
```

## Before final submission

Update the canonical URL and Open Graph URL in `index.html` from `https://example.com/` to the actual GitHub Pages URL.

Run the deployed URL through Google PageSpeed Insights and test desktop/mobile views and all links.
